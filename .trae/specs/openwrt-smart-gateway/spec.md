# OpenWrt智能网关集成方案 Spec

## Why

用户希望将ZeroClaw部署在OpenWrt路由器上，作为智能网络管理中枢，实现：
1. 自然语言驱动的网络管理与行为控制
2. 网络安全威胁检测与自动防护
3. 智能网络拓扑自动配置
4. OpenWrt插件自动化部署与管理
5. 智能家居控制中心
6. 自动化资源下载与整理
7. 私有知识管理与个人助理功能

## What Changes

### 核心变更
- 新增 `src/openwrt/` 模块 - OpenWrt系统集成层
- 新增 `src/network/` 模块 - 网络管理工具集
- 新增 `src/automation/` 模块 - 自动化技能包系统
- 扩展 `src/tools/` - 网络配置、防火墙、流量分析工具
- 扩展 `src/channels/` - 管理员交互通道优化
- 新增 `src/homekit/` 模块 - 智能家居集成

### 功能模块
- **操作回滚系统**: 配置快照、变更记录、一键回滚、安全恢复
- **精细化行为管理**: 设备级控制、应用级控制、时段控制、行为审计
- **网络管理工具**: 防火墙规则、上网时长控制、内容过滤、流量统计
- **安全监控工具**: 入侵检测、异常流量分析、自动策略响应
- **拓扑发现工具**: 网络探测、设备识别、自动配置
- **插件管理工具**: opkg包管理、服务配置、Docker管理
- **智能家居工具**: MQTT集成、HomeAssistant桥接、设备控制
- **下载管理工具**: aria2集成、资源搜索、自动整理

## Impact

- Affected specs: 网络管理、安全防护、智能家居、自动化
- Affected code: 
  - `src/tools/` - 新增网络相关工具
  - `src/channels/` - 优化管理员交互
  - `src/security/` - 扩展网络安全能力
  - `src/peripherals/` - 支持OpenWrt设备

## 可行性分析

### 0. 操作回滚系统 (可行 ✅)

**需求**: 所有网络配置操作支持回滚，避免配置错误导致网络不可用

**技术方案**:
- 实现配置快照系统，在每次变更前自动备份当前配置
- 使用Git-like版本控制管理配置变更历史
- 实现变更记录追踪，记录操作人、时间、变更内容
- 提供一键回滚到任意历史版本的能力

**实现路径**:
```
配置变更请求 → 创建快照 → 执行变更 → 记录变更日志 → 
确认成功/失败 → 失败时自动回滚 / 成功时保留快照
```

**关键组件**:
- `config_snapshot` - 配置快照管理
- `config_diff` - 配置差异对比
- `config_rollback` - 配置回滚执行
- `change_journal` - 变更日志记录

**复杂度**: 中等 - 需要设计可靠的快照存储和回滚机制

**安全设计**:
- 快照存储在独立分区/存储，避免系统故障丢失
- 保留最近N个快照（可配置，默认10个）
- 支持紧急恢复模式（物理按键触发）
- 变更超时自动回滚（可配置，默认60秒无确认）

### 0.1 精细化家长控制 (可行 ✅)

**需求**: 针对家长控制小孩使用网络的场景，实现精细化的网络行为管理

**用户场景示例**:
> 作为家长，我希望：
> - 限制小孩设备（手机/平板/电脑）只能在特定时段上网
> - 禁止小孩访问游戏网站和社交媒体
> - 限制小孩每天玩游戏的总时长
> - 允许小孩访问学习网站但禁止娱乐内容
> - 在小孩尝试访问被禁止内容时收到通知
> - 可以临时放宽限制（如周末、假期）

**技术方案**:

#### 设备识别与分组
- 支持按MAC地址、IP地址、主机名识别设备
- 支持设备分组（如"小孩设备"、"成人设备"、"访客设备"）
- 支持设备别名和备注（如"小明的iPad"）

#### 行为控制维度
| 控制维度 | 说明 | 示例 |
|---------|------|------|
| 时间控制 | 允许上网的时段 | 周一到周五 18:00-21:00 |
| 时长控制 | 每日总上网时长 | 每天最多2小时游戏时间 |
| 内容控制 | 允许/禁止的网站类别 | 禁止游戏、社交媒体 |
| 应用控制 | 允许/禁止的应用 | 禁止王者荣耀、抖音 |
| 流量控制 | 上传/下载速度限制 | 游戏流量限速100KB/s |

#### 规则模板
预设常用规则模板，家长可快速应用：
- **学习模式**: 仅允许教育网站，禁止游戏和社交媒体
- **娱乐模式**: 允许游戏和社交媒体，但有时长限制
- **睡眠模式**: 禁止所有网络访问
- **自由模式**: 无限制（可设置总时长上限）

**实现路径**:
```
家长设置规则 → 设备识别 → 规则匹配 → 
流量检测 → 行为判断 → 执行策略 → 记录日志 → 通知家长
```

**关键工具**:
- `device_group_manage` - 设备分组管理
- `rule_template_apply` - 规则模板应用
- `time_quota_manage` - 时长配额管理
- `content_category_filter` - 内容分类过滤
- `app_control_rule` - 应用控制规则
- `behavior_audit_log` - 行为审计日志
- `parent_notify` - 家长通知推送

**复杂度**: 中高 - 需要实现DPI（深度包检测）进行应用识别

**需求**: 自然语言控制网络过滤、上网时长管理、内容管理、行为管理

**实现路径**:
```
用户自然语言 → LLM理解意图 → 调用网络管理Tool → 
执行iptables/nftables命令 → 返回结果
```

**关键工具**:
- `network_firewall` - 防火墙规则管理
- `network_schedule` - 上网时段控制
- `network_content_filter` - 内容过滤规则
